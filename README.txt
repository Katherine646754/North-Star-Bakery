The website uses:
- One external CSS stylesheet
- A 4-color bakery-inspired palette
- Two font families (Georgia for headings and Arial for body text)
- Mobile-first styling
- Flexbox
- A desktop media query at 768px
- Responsive images with <picture>
- Audio/video fallback text
- Accessible labels, fieldsets, legends, alt text, and built-in form validation

Important:
The Contact form currently uses action="#" because Touchstone 2 did not provide a live form-processing URL. The form is included for the assignment requirements but does not send submissions to a real server.
